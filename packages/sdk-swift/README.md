# KeChat Swift SDK

Official Swift SDK for KeChat - iOS native integration.

## Status

🚧 **Under Development** - Coming soon in Phase 2

## Features (Planned)

- 🔐 End-to-end encrypted messaging
- 💰 Payment integration (M-Pesa, Airtel Money)
- 📞 Voice and video calling
- 👤 User authentication
- 🏪 Marketplace integration
